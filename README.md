# DrunkFlow - Distribuidora de Bebidas

Uma plataforma web moderna e responsiva para a distribuidora DrunkFlow, especializada em bebidas alcoólicas e não alcoólicas. O site oferece catálogo de produtos, carrinho de compras interativo, busca avançada e formulários de contato.

## 🚀 Funcionalidades

- **Catálogo de Produtos**: Explore uma ampla seleção de cervejas, vinhos, destilados, refrigerantes, sucos e energéticos.
- **Busca Interativa**: Barra de pesquisa com sugestões em tempo real e filtros por categoria/preço.
- **Carrinho de Compras**: Adicione produtos, visualize itens e finalize pedidos.
- **Galeria de Imagens**: Lightbox para visualizar produtos em destaque.
- **Formulários**: Contato e login com validação.
- **Design Responsivo**: Otimizado para desktop, tablet e mobile.
- **Acessibilidade**: Semântica HTML5, ARIA labels e navegação por teclado.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível.
- **CSS3**: Estilos modernos com Flexbox, Grid e animações.
- **JavaScript (ES6+)**: Interatividade, manipulação do DOM e localStorage para carrinho.
- **SVG**: Ícones vetoriais para botões e navegação.
